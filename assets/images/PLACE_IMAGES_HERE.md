# Image Assets — Jesus is LORD Radio

Place the following image files in this folder:

| Filename                | Description                          | Dimensions      |
|-------------------------|--------------------------------------|-----------------|
| `logo.png`              | Ministry dove/globe logo (WHITE)     | 200×200px       |
| `favicon-32.png`        | Favicon for browser tab              | 32×32px         |
| `favicon-16.png`        | Favicon small                        | 16×16px         |
| `apple-touch-icon.png`  | iOS home screen icon                 | 180×180px       |
| `og-image.jpg`          | Social media share image             | 1200×630px      |

## Getting the Logo
The logo is a white dove over a globe on a transparent background.
It should match the branding image supplied (dove on deep blue circle).

## Generating Favicons
1. Export your logo as a 512×512 PNG
2. Go to https://favicon.io/favicon-converter/
3. Upload the PNG and download the generated pack
4. Place the files here with the names listed above
